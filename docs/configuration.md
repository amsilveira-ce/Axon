# Configuration

## axon.config.json

Generated by `axon init`. All fields have defaults and can be changed manually.

```json
{
  "version": "0.1.0",
  "data_dir": ".axon",
  "pa": {
    "port": 4100,
    "default_mode": "agent",
    "default_reasoning_mode": "react",
    "gateways": [],
    "max_iterations": 10,
    "cache": true,
    "llm": {
      "host": "http://localhost:11434",
      "model": "llama3.2",
      "timeout": 60
    },
    "window_size": 10
  },
  "ga": {
    "port": 5000
  }
}
```

### Fields

**`data_dir`**
Directory where Axon stores runtime data (registry, tokens, sessions, traces). Defaults to `.axon` relative to the current directory. Can be overridden by the `AXON_DATA_DIR` environment variable.

**`pa.port`**
Port for the PA control API. Default: `4100`.

**`pa.default_mode`**
Operational mode. Options: `agent` (fully autonomous), `copilot` (human-assisted), `no-llm` (deterministic). Default: `agent`.

**`pa.default_reasoning_mode`**
Reasoning strategy used by the PA. Options: `react`, `rewoo`, `tot`. Default: `react`.

**`pa.max_iterations`**
Maximum number of planning/execution cycles per request. Default: `10`.

**`pa.llm.host`**
Ollama server URL. Default: `http://localhost:11434`.

**`pa.llm.model`**
Model used by the PA for intent extraction and reasoning. Default: `llama3.2`. Reasoning models (e.g. `deepseek-r1:14b`) produce better results for complex queries.

**`pa.llm.timeout`**
Timeout in seconds for LLM calls. Default: `60`.

**`pa.window_size`**
Number of conversation turns kept in the active context window. Older turns are summarized and stored in `summary`. Default: `10`.

**`ga.port`**
Port for the GA API. Default: `5000`.

## Environment variables

**`AXON_DATA_DIR`**
Overrides `data_dir` from `axon.config.json`. Takes priority over the config file. Accepts absolute or relative paths.

```bash
# container / production
AXON_DATA_DIR=/var/lib/axon axon pa run --query "..."

# or in docker-compose
environment:
  - AXON_DATA_DIR=/data/axon
```

## Data directory structure

```
{data_dir}/
├── ga/
│   ├── registry.json       # registered resources
│   ├── tokens.json         # registration tokens
│   └── traces/             # GA operation logs
└── pa/
    ├── sessions/           # ConversationHistory per session_id
    ├── resource_cache.json # cross-session resource cache
    ├── memory_bank.json    # domain defaults and user preferences
    └── traces/             # LLM reasoning logs
```
